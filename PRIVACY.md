# Данные и приватность

Dictate не содержит аналитики, рекламы и телеметрии.

Во время распознавания приложение отправляет аудио выбранному пользователем провайдеру: ElevenLabs, OpenRouter или Google AI Studio. Условия хранения и обработки запроса определяются провайдером и аккаунтом пользователя.

История выключена по умолчанию. При обычной диктовке аудио и результат остаются в памяти до завершения экрана; автоматического копирования нет. Ручное копирование передаёт текст в системный буфер обмена. Настройки и зашифрованные ключи сохраняются отдельно.

После явного включения истории на устройстве сохраняются до десяти записей с текстом. Отключение истории не удаляет старые записи; для этого есть «Очистить всю историю» и удаление отдельной записи. Обработка после удаления не восстанавливает текст. Системный backup и перенос данных отключены.

Аудио, API-ключи, словарь, распознанный текст и тела ошибок API не пишутся в журнал. Короткая техническая диагностика может содержать тип отказа, выбранную модель и длительность операции. Автоматических повторов платного запроса нет.

OpenRouter передаёт запрос конечному провайдеру модели. Google Interactions вызывается с `store=false`; это не обещание нулевого хранения всеми участниками цепочки. Действуют условия провайдера и выбранного аккаунта. Облачная отправка требует сети и может тарифицироваться.

API-ключи шифруются AES-GCM ключом из Android Keystore. Это защищает обычное хранилище приложения, но не заменяет лимиты расходов и отдельный ключ для мобильного клиента.
