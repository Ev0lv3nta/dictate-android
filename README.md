# Dictate

[![CI](https://github.com/Ev0lv3nta/dictate-android/actions/workflows/ci.yml/badge.svg)](https://github.com/Ev0lv3nta/dictate-android/actions/workflows/ci.yml)
[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Dictate — голосовой ввод для Android со своим API-ключом. Можно диктовать прямо в приложении или подключить его как сервис к клиенту, который использует стандартный `SpeechRecognizer`.

Есть адаптеры ElevenLabs, OpenRouter и Google AI Studio. Аудио отправляется выбранному провайдеру; локального распознавания нет. Ключи шифруются через Android Keystore, встроенных ключей нет.

<img src="docs/media/home-ru.png" alt="Главный экран Dictate" width="260">

Скриншот приложения на эмуляторе Android 16. [Экраны и условия проверки](docs/testing.md).

## Возможности

- диктовка → текст → ручное копирование;
- `RecognitionService` с явным списком разрешённых клиентов;
- автостоп по тишине и ограничение длительности записи;
- выбор провайдера, модели, языка и словаря терминов;
- необязательная локальная история: до десяти записей, по умолчанию выключена;
- повторное распознавание сохранённого аудио другой моделью;
- русский и английский интерфейс, светлая и тёмная тема;
- без рекламы и аналитики.

## Установка и настройка

Готовая сборка публикуется в [Releases](https://github.com/Ev0lv3nta/dictate-android/releases). Для работы нужны Android 8.0 или новее, разрешение на микрофон и API-ключ выбранного провайдера.

Для диктовки в приложении:

1. В настройках выберите провайдера и сохраните его API-ключ. Сохранение не делает платный запрос и не проверяет доступ к модели.
2. На главном экране нажмите «Диктовать» и разрешите микрофон.
3. Завершите запись, дождитесь текста и скопируйте его. Во время обработки запрос можно отменить.

История включается отдельно. Условия API и стоимость определяются провайдером; скрытых повторов и автоматической смены модели нет.

## Подключение клиента

Для внешнего клиента дополнительно разрешите видимый индикатор записи и добавьте пакет клиента в «Разрешённые приложения». Пустой список блокирует внешние вызовы. Проверить подключение можно отдельным [sample-приложением](sample-client), APK которого тоже есть в Releases.

Явный компонент:

```java
ComponentName component = new ComponentName(
        "io.github.ev0lv3nta.dictate",
        "io.github.ev0lv3nta.dictate.DictateRecognitionService");
SpeechRecognizer recognizer = SpeechRecognizer.createSpeechRecognizer(context, component);
```

На прошивках с выбором системного провайдера Dictate виден по intent `android.speech.RecognitionService`. Полный lifecycle, разрешения и поддержанные параметры описаны в [подключении клиента](docs/integration.md).

Совместимость с любой закрытой клавиатурой не гарантируется: часть клавиатур всегда использует собственный движок и не позволяет заменить его. Для таких приложений требуется поддержка системного `SpeechRecognizer` со стороны разработчика клавиатуры.

## Сборка

Нужны JDK 17 и Android SDK 36:

```bash
./scripts/verify.sh
```

Debug APK: `app/build/outputs/apk/debug/`. Локальный `assembleRelease` создаёт неподписанный APK; готовые релизы подписывает отдельный workflow. [Подпись и выпуск](docs/releasing.md).

Наличие конкретных моделей и условия API меняются у провайдеров. Каталог моделей находится в `ModelCatalog.java` и обновляется вместе с приложением.

## Состояние проекта

`0.2.0` — предварительный релиз. Автоматические проверки разделяют контракты провайдеров, Android IPC и настоящий виртуальный микрофон. Fixture-ответ не выдаётся за облачное распознавание. Live API не проверялись: ключи для прогона не предоставлены. Проверки на физическом телефоне и гарантий для OEM-прошивок нет. Подробности — в [матрице тестов](docs/testing.md).
