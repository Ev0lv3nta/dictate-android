## Dictate 0.2.0

- Самостоятельная диктовка с главного экрана; внешний SpeechRecognizer-клиент в отдельном APK.
- Изолированные сессии, стандартные stop/cancel, видимый индикатор микрофона и явный доступ клиентов.
- История выключена по умолчанию; восстановление записей, зашифрованные ключи и безопасные ошибки API.
- Русский и английский интерфейс, крупный шрифт и тёмная тема.
- Подписанные APK приложения и sample; контрольные суммы в SHA256SUMS.

Предварительный релиз. Виртуальный микрофон и fixture-провайдер проверяют аудиотракт и IPC, а не облачное распознавание. Live API не запускались — ключи для проверки не предоставлены. Проверки на физическом телефоне нет; совместимость с произвольной клавиатурой не гарантируется.

Неподписанный `v0.1.0` не был устанавливаемым релизом. Новые APK используют постоянный релизный сертификат; [инструкция](https://github.com/Ev0lv3nta/dictate-android/blob/main/docs/releasing.md).
