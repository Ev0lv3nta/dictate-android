# Устройство приложения

`HomeActivity` запускает короткую диктовку. `RecorderActivity` отвечает за сохранённые записи, прослушивание и повторное распознавание. Настройки применяются отдельно; ключи не передаются через Intent.

Внешний клиент использует `SpeechRecognizer` и `DictateRecognitionService`. Сервис проверяет микрофон и вызывающий UID, затем создаёт `DictationSession`. На Android 12+ пакет сверяется с UID через AppOps, а контекст AudioRecord содержит AttributionSource клиента. До Android 12 используются пакеты UID. При shared UID приложения нельзя считать независимо изолированными.

## Одна сессия

Подготовка → запись → обработка → результат или ошибка. `stopListening` завершает запись и оставляет обработку; `cancel` закрывает AudioRecord и HTTP Call, отбрасывает отложенные callbacks. Каждая операция освобождает только собственный токен `OperationGate`. Параллельная диктовка, повторная обработка или прослушивание не открывают второй поток.

Настройки копируются при старте. AudioRecord записывает mono PCM16, 16 кГц; захват и обрезка тишины используют один порог. Максимум — 300 секунд / 9,6 МБ PCM. Провайдер получает один POST, без автоматических повторов и перехода на другую модель. HTTP ограничен общим deadline 120 секунд, ответ — 2 МБ. Исключения содержат только безопасную категорию ошибки, не тело ответа.

Внешняя запись использует видимую кнопку поверх клиента и microphone foreground service. Запуск ждёт отображённого кадра окна, а не таймера. Обработка меняет кнопку на отмену и выключает microphone FGS. При результате, ошибке, отмене и уничтожении сервиса окно убирается. Встроенному экрану разрешение на показ поверх приложений не нужно.

## Данные

По умолчанию PCM и текст живут только в памяти. История включается отдельно: приватные PCM-файлы и атомарный JSON-индекс, до десяти записей и 72 МБ суммарно. При восстановлении недостающие файлы исключаются, оставшиеся PCM без индекса возвращаются без текста. Удалённая запись не появляется от позднего результата.

API-ключи шифруются AES-GCM через Android Keystore. Повреждённые данные отличаются от отсутствующего ключа: приложение предлагает ввести его снова. Backup и перенос данных отключены.

## Граница тестовой сборки

`integration` содержит fixture-провайдер, который проверяет введённый в микрофон сигнал 440 Гц. В `debug` и `release` компилируется другой `BackendSelection`: только реальные адаптеры и обязательный API-ключ. Intent, настройки и sample не могут включить fixture в обычном APK. Sample — самостоятельное приложение, без зависимости на `:app`.

Платформенные контракты: [RecognitionService](https://developer.android.com/reference/android/speech/RecognitionService), [ограничения FGS](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start), [видимый overlay в Android 15](https://developer.android.com/about/versions/15/behavior-changes-15#fgs-system-alert-window).
